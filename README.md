## Crafticulum release

The self-hosted site, ready to upload. No config.php and no data folder inside, so your settings and keys are never touched.

- `crafticulum/`: every file of the current release (v106, 19 Nov 2026: class lists from a CSV file with first name, last name and student reference; a red Go live button at the top of the board). Upload the contents of this folder over the live site, including `.htaccess`.
- `crafticulum-v106.zip` and `crafticulum-release.zip`: the same files as one zip (1,814,740 bytes).

Read `crafticulum/README.txt` for what changed and how to set things up.
