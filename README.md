## Crafticulum release

The self-hosted site, ready to upload. No config.php and no data folder inside, so your settings and keys are never touched.

- `crafticulum/`: every file of the current release (v100, 19 Nov 2026: both sign-up forms search the schools list as you type; a request made through a college goes to that college's manager). Upload the contents of this folder over the live site, including `.htaccess`.
- `crafticulum-v100.zip` and `crafticulum-release.zip`: the same files as one zip (1,807,164 bytes).

Read `crafticulum/README.txt` for what changed and how to set things up.
