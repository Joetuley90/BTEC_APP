- `crafticulum/`: every file of the current release (v99, 19 Nov 2026: asking to join a college with manager approval; profiles and the institution directory in SQLite tables; lists uploaded from the browser as CSV or Excel with columns worked out; the profile steps open once for someone new; the profile sets where planning and the library start). Upload the contents of this folder over the live site, including `.htaccess`.
- `crafticulum-v99.zip` and `crafticulum-release.zip`: the same files as one zip (1,802,322 bytes).

Read `crafticulum/README.txt` for what changed and how to set things up.
